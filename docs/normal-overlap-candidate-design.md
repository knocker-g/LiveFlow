## Position correction first

Use viewport CSS pixels at proof evaluation time. The actual overlaySurface DOM bounds (after player/video intersection) are coordinate authority, not unconditionally video.right/top. Renderer enters at surface.right and exits at surface.left-width. Candidate x must be surface.right, full actual measured width (not intersection-clipped width); y/height and velocity must match selected rendered node. Add exitX=surface.left and surfaceRight to immutable proof facts, so finite coexistence ends when either box exits that surface. Read active DOM boxes at the snapshot timestamp, paired with immutable launch velocity and semantic class; do not assume a cached viewport origin survives native page layout shifts.

Before changing overlay surface inline bounds, if active nodes exist and the requested relative surface rect differs from the installed one, hold new launches until they naturally retire; never resize/reposition their ancestor from this operation. External page shifts are observational facts, not permission to relayout active nodes. At commit compare actual surface bounds, selected measured width/height/velocity, generation/revision with proof. Refresh geometry; reread active boxes at commit time, and rerun the selected collision policy plus entire travel-strip subtitle exclusion before animation. Store snapshotAtMs/geometryRevision with proof; reject time reversal or changed surface/geometry. No stale proof reuse.

Old Baseline/A/B fixture launch/drop/density/overlap counters and preview positions are invalidated by this correction, not authority for the new C. Role CSS, ingress, retention semantics, direct overlap-duration regression and unrelated safety evidence remain reusable.

## C-only policy

Only DENSE/MAX_READABLE; only pairs with explicit NORMAL semantic class at both ends. Any missing/unrecognized class or SPECIAL retains legacy proof. Keep base/interleaved generator and B config as reference. NORMAL/COMPACT remain legacy.

For NORMAL pair, compute exact horizontal interval intersection over finite coexistence, constant immutable velocities, ending at the earlier of either box's exit. Bound vertical depth fraction relative to both boxes, horizontal depth fraction relative to both widths, pair occluded area fraction for both boxes, actual intersection duration and catch-up ratio. Shallow vertical intersection (<=0.5 of each height; both fractions must pass) may relax the -24px floor only within all C budgets: max horizontal depth fraction0.35, max pair area fraction0.18, max duration1.4s, max catch-up ratio1. Deep/same-row falls back to strict B proof. A full passing path necessarily crosses horizontal depth fraction1 for at least the smaller box and is rejected. SPECIAL pairs use legacy bounds, never this branch. Relaxed overlap is forbidden whenever either participating box is partly clipped by entry/exit during the overlapping interval: use strict legacy proof for that pair instead. Visibility denominator for relaxation is thus each fully visible measured rectangle's width*height, never an offscreen portion.

Concurrency: max2 simultaneous overlapping neighbours per candidate and per affected active NORMAL, including SPECIAL or unknown neighbours under unchanged strict pair policy; minimum visible fraction0.65 for both candidate and each affected active at every future event time (sum of pair occluded area upper bounds, conservatively double-count intersections). Include active-active overlaps in the affected active's budget. Validate relevant active pairs and their future boundaries rather than only summing overlaps at launch. Mixed-class/partly clipped neighbours cannot obtain a relaxation; if aggregate visibility cannot be proved conservatively from full visible boxes, fail closed to strict policy. Reject unknown/unrepresentable geometry. Finite future critical times are pair interval entry/exit, surface entry/exit and all edge alignments; horizontal intersection area is piecewise linear, so evaluate all joint breakpoints across all neighbours. Do not independently approve many pair overlaps without aggregate budget.

Candidate values are provisional experiment bounds, not LOCK: half-step gives16/32=0.5 vertical fraction;0.35 horizontal allows roughly one third of a line intersecting a half-height edge, area<=0.175, leaving>=0.825 pair visibility. Aggregate0.35 permits at most two such edge overlaps, still >=0.65 visible; no numeric sweeps. Equal-speed persistent edge overlap must fail duration. Barely shallow vertical geometry does not exempt duration/horizontal depth. Deep rows retain -24px. Tests must cover threshold edges, unequal sizes/speeds, current overlap, future overlap, multiple neighbours, SPECIAL, unknown semantic class and concurrency on existing comments.

No source threshold, stale, role priority, request/authority, opportunity count or active relayout changes. Production position correction is separable. C policy stays opt-in candidate-only until Human selects; no default C adoption. After deterministic tests, short same-episode B/C real-video comparison uses identical source/layout and measured DOM, no transport forgery. Failure of runtime qualification stops headed comparison.

Aggregate rejection cannot fall back to strict proof and bypass a measured concurrency/visibility violation. Fallback is only for ineligible pair relaxation (deep/mixed class/partial clipping), not a proved placement budget violation.

Independent design review: requested coordinate/time/clipping and aggregate clarifications incorporated; reviewer approved these exact final requirements before implementation. Numeric budgets remain provisional, not final LOCK.

## Partial-entry/exit refinement for review

Full-visibility eligibility over the entire interval would exclude every closing overlap that lasts until natural exit, making C unable to discriminate the target. Instead compute actual visible intersections clipped to surface left/right at every joint breakpoint; use each subject's visible width*height as visibility denominator. Preserve full-box horizontal-depth and pair-area bounds, duration and no full passing. Fully visible subjects retain>=0.65 aggregate visible fraction. Partly clipped subjects require>=0.5 aggregate visible fraction, max2 neighbours and the same1.4s total overlap interval; crop itself is not counted as occlusion. Ignore zero-width fully exited subjects. At piecewise-linear numerator/denominator breakpoints, evaluate the limiting ratio approaching any zero-width edge as well; ratios are monotone between breakpoints. This explicit edge budget is provisional C, not approval of sustained half-text occlusion. SPECIAL mixed pairs never relax; measured aggregate rejection never bypasses. Earlier full-visibility-only eligibility is superseded only after independent approval of this refinement.

Independent refinement review APPROVED with requirements incorporated: duration1.4s is the union episode of any positive occlusion across all neighbours, not independent pair durations. Both one-sided visibility limits at full/clipped transitions and zero-width edges are evaluated. Initial offscreen entry still verifies all future visible intervals. Concrete C numbers are provisional candidate-only. Canonical principles recorded before implementation; no stronger fixed -24px LOCK conflict found.


## Continuous elapsed-episode review

Absolute occlusion episodes retain their historical starts across new launches and departed neighbours. Merge elapsed and prospective intervals before approving, rather than restarting a1.4s budget at each launch. Under C configuration every launch validates affected existing NORMAL aggregate budgets, including lower-density strict launches and SPECIAL candidates. This adds no SPECIAL relaxation. Preserve unknown history during current occlusion; only an observed absence of current occlusion or already-known history makes it known. Record histories separately from immutable trajectories.
